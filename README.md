# 🌐 Front-End Web Technology (FEWT)

Laboratory practicals, coursework exercises, and practice projects covering the foundations of front-end web engineering.

---

## 🛠 Technologies Explored

* **HTML5:** Semantic elements, forms, audio/video integration, canvas.
* **CSS3:** Flexbox, Grid layouts, animations, transitions, responsive media queries.
* **JavaScript:** DOM manipulation, event handling, ES6+ features.

---

## 📁 Repository Structure

* `Lab/` — University practical lab solutions and task submissions.
* `Practice/` — Standalone experimental webpages and UI exercises.
* `Paper/` & `PPT/` — Theoretical study notes and conceptual presentations.
